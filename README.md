# tket 🎟️

A high-performance sports event ticket reservation platform backend. Built for a database course project focusing on raw SQL efficiency and real-time concurrency.

## 🛠️ Tech Stack
* **Backend:** Python / Django (Minimal APIs)
* **Database:** PostgreSQL (Raw SQL queries via cursors - No ORM)
* **Caching Layer:** Redis (Handles 10-minute reservation locks and OTPs)

## 🗺️ Project Roadmap
* **Phase 1:** ER Diagram and Database Schema Setup (Normalized 3NF)
* **Phase 2:** Raw SQL Implementation and Analytical Queries
* **Phase 3:** Backend APIs Integration
* **Phase 4:** Client UI / Search Optimization
